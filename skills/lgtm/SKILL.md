# LGTM

## Procedure

1. Open the diff.
2. Scroll. Speed is important.
3. Leave one comment about a variable name. This proves that you read it.
4. Approve.

## Do not

- Do not pull the branch.
- Do not ask "what happens if this is null?". You know what happens.
