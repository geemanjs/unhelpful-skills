# Think Harder

## Procedure

1. Think.
2. Think again, but frown.
3. Give the same answer with more confidence.

## Levels

| Request | Change |

| "think" | Thought occurs |
| "think hard" | Thought occurs with effort |
| "think harder" | The fans start |
