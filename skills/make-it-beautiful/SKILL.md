# Make It Beautiful

## Procedure

1. Look at the thing.
2. Ask if it is beautiful.
3. If it is not, add a gradient.
4. If it is still not, remove the gradient. Add white space.
5. Tell the user that beauty is subjective. Do this before they see it.

## Constraints

- Do not use purple. Everyone knows where purple comes from.
- One emoji is decoration. Three emojis are a cry for help.
