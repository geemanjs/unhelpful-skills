# Make It Work

## Procedure

1. Find the reason that it does not work.
2. Remove that reason.
3. Check that it works.

## Common mistakes

- You made it work differently. That is a feature, not a fix.
- You made the test work and not the code. Put the assertion back.
- You said that it works and did not run it. That is hope.
